# Verification Summary Report — NeuroPulse System

This report summarises the verification of the system, component by
component: for each requirement allocated to a component, the protocols
that verify it, their executions and results. The procedures are in [[DOC-0004]] and
their executions are reported in [[DOC-0005]].

A Verification Summary Report is a type of its own that extends Document:
its sections are its template's, so every report of this type lays out
its scope the same way. The report holds only this prose and its scope, a
query for the top of the component tree; each component gets a section of
the requirements allocated to it, and each subcomponent a subsection of its
own, so a component or requirement added later is in the next export of
this report without editing it.
