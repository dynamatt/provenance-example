# Verification Summary Report — Amplitude Control

This report summarises the verification of the amplitude control
requirements: for each requirement in its scope, the protocols that verify
it, their executions and results. The procedures are in [[DOC-0004]] and
their executions are reported in [[DOC-0005]].

A Verification Summary Report is a type of its own that extends Document:
the matrix below is its template's, so every report of this type lays out
its scope the same way, and the report itself holds only this prose and the
requirements it covers.
