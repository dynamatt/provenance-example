# Risk Management Summary

This summary shows the identified risks and the requirements of the
amplitude control function in one list, in author-assigned order, so a
reviewer reads each risk beside the requirements written around it. One
query block selects both types (provenance-ddf REQ-0082). Each type is
shown through a named presentation template chosen for this document
(REQ-0079):
requirements as checklist lines, risks as summaries. DOC-0001 shows the
same requirements in full.

## Risks and requirements

```query
from: [Risk, Requirement]
order_by: order
templates:
  Requirement: requirement-checklist
  Risk: risk-summary
```

Requirements that control a risk are listed on the risk as *mitigated by*,
for example [[RSK-0001]] is mitigated by [[REQ-0002]].

## Open items

Requirements not yet approved, listed by ID:

```query
from: Requirement
where:
  field: status
  operator: not_equals
  value: approved
render: id
```

## Sources

The standards and literature the risk file draws on, by their identifier.
A query block lists entities rather than citing them, so these are not
numbered and this summary has no reference list of its own:

```query
from: Reference
order_by: year
render: field:identifier
```
